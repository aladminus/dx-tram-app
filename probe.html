dx-tram – Capability Test

Checks whether this browser and network can run the planned single-file dx-tram app (PRD PL-1..PL-3, ST-1, IN-5). Run it in both modes (PRD §3): offline = this file opened by double-click (file://), and online = the copy at https://aladminus.github.io/dx-tram-app/probe.html. In offline mode the Overpass rows are expected to FAIL (no Referer); in online mode they should pass. It contacts only: Esri map tiles, three Overpass (OpenStreetMap) servers, and three elevation services. Nothing is uploaded.
