# dx-tram (app)

Published build of **dx-tram**, a tram-infrastructure investigation tool working on OpenStreetMap data (tight curves, track spacing, platforms, electrification, assets).

- **Online:** https://aladminus.github.io/dx-tram-app/ (fetch OSM data + all processing)
- **Offline:** download `index.html` and open it from disk (all processing, no fetching)

Both work on the same local project folders; nothing is uploaded. Development happens in a separate repository; this one holds only the built file.

Currently (preparation phase) it holds only `probe.html`, a browser capability test: https://aladminus.github.io/dx-tram-app/probe.html

Map data © OpenStreetMap contributors, available under the Open Database License.
